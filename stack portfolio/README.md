# 🤖 DathBot – Rule-Based Customer Support Chatbot

## 📌 Project Overview

DathBot is a Python-based Rule-Based Customer Support Chatbot developed to provide automatic responses to common customer queries. It helps users get information about business hours, products, pricing, delivery, returns, refunds, and customer support.

The chatbot uses predefined keywords and regular expressions to identify user queries and generate appropriate responses. It also supports greetings, goodbye messages, multiple-intent recognition, and JSON-based FAQ data storage.

## 🎯 Objectives

- To automate basic customer support interactions.
- To provide quick responses to frequently asked questions.
- To understand keyword-based chatbot development.
- To implement Python concepts such as functions, loops, and file handling.
- To store and manage FAQ information using JSON.

## ✨ Features

- **Greeting Detection:** Responds to greetings such as Hi, Hello, and Hey.
- **Business Hours:** Provides company working hours.
- **Product Information:** Answers basic product and service queries.
- **Pricing Information:** Responds to price and cost-related questions.
- **Delivery Support:** Provides delivery and tracking information.
- **Return and Refund Support:** Handles return, refund, and exchange queries.
- **Contact Support:** Guides users to customer support.
- **Multiple Intent Recognition:** Identifies multiple topics in one message.
- **JSON Data Storage:** Saves and loads FAQ information.
- **Error Handling:** Handles unexpected errors without immediately crashing.
