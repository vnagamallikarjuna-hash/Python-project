# 🤖 DathBot – Rule-Based Customer Support Chatbot

## 📌 Project Overview

DathBot is a Python-based Rule-Based Customer Support Chatbot designed to provide automatic responses to frequently asked customer questions.

The chatbot helps users get information about business hours, products, pricing, delivery, returns, refunds, and customer support. It uses predefined keywords and regular expressions to identify user queries and generate suitable responses.

The project also uses JSON to store FAQ data, allowing the chatbot to load frequently asked questions from an external file. It includes greeting detection, time-based greetings, multiple-intent recognition, input validation, and error handling.

## 🎯 Objectives

- To develop a basic customer support chatbot using Python.
- To automate responses to common customer queries.
- To understand keyword-based intent recognition.
- To implement regular expressions for text matching.
- To store and manage FAQ information using JSON.
- To improve Python programming and problem-solving skills.

## ✨ Features

- **Greeting Detection:** Responds to Hi, Hello, Hey, and other greetings.
- **Business Hours:** Provides company working hours.
- **Product Information:** Answers product and service-related queries.
- **Pricing Information:** Handles price and cost-related questions.
- **Delivery Support:** Provides delivery and tracking information.
- **Return and Refund Support:** Handles return, refund, and exchange queries.
- **Contact Support:** Guides users to customer support.
- **Multiple Intent Recognition:** Identifies multiple topics in a single message.
- **Time-Based Greetings:** Displays greetings according to the current time.
- **JSON FAQ Storage:** Saves and loads FAQ information.
- **Help Command:** Displays the topics supported by the chatbot.
- **Error Handling:** Handles unexpected errors during execution.
