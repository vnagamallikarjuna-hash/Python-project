🎮 Hangman Word Guessing Game

📌 Project Overview

The Hangman Word Guessing Game is a console-based Python project in which players guess a hidden English word one letter at a time. The game displays ASCII hangman artwork and allows a maximum of six incorrect guesses.

🎯 Objectives

- Develop an interactive word guessing game using Python.
- Practice string manipulation and control flow.
- Understand lists, sets, functions, and random word selection.
- Validate user input and prevent duplicate guess penalties.

✨ Features

- Random word selection.
- Letter-by-letter word guessing.
- ASCII hangman artwork.
- Maximum of six incorrect guesses.
- Duplicate guess detection.
- Input validation.
- Victory and defeat messages.
- Option to quit the game.

🛠️ Technologies Used

- Programming Language: Python 3
- Code Editor: Visual Studio Code
- Library: Python Standard Library ("random")

▶️ How to Install and Run

Prerequisites

- Python 3 installed on your computer.
- Visual Studio Code or another Python editor.

Steps

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

python hangman.py

For Windows, you can also use:

py hangman.py

🎮 How to Play

1. Run the Python program.
2. The game selects a random secret word.
3. Guess one alphabet letter at a time.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses update the hangman artwork.
6. You have six incorrect guesses available.
7. Guess the complete word to win.
8. If you use all six incorrect guesses, the game ends in defeat.
9. Type "quit" to exit the game.
